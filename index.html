One-hand signs

These work right away, with either hand. Change what each one says, or switch off any sign you do not want. Tip: switch off signs that look like a resting hand, so it never speaks by accident.

A signs file lists each sign's name, message and on/off. Save one, edit it in any text editor, then load it. Or place it next to this page as signs.json and it loads automatically.

Your own signs (optional)

Add a personal sign the built-in ones do not cover. Tap it, tap Record, then show the sign for 5 seconds, moving the hand slightly. Also record NEUTRAL (relaxed hand) so a resting hand is never read as a sign.

Settings

Longer = fewer accidental messages.

Higher = only very sure matches are accepted.

Tip: use a plain background and good light, with the whole hand in view.
